# Income Convergence Analysis Using R

## Project Overview

This project examines the relationship between initial GDP per capita and subsequent economic growth across countries. It also explores how human capital is associated with economic growth.

## Data Sources

- Penn World Table 10.0 (PWT)
- World Bank World Development Indicators (WDI)

## Tools and Methods

The analysis was conducted in R using packages including `dplyr`, `tidyr`, `ggplot2`, `pwt10`, and `WDI`.

The project includes:
- Data collection, cleaning, and merging
- Calculation of GDP per capita and annualized growth rates
- Data visualization across six time periods
- Multiple linear regression using initial GDP per capita and human capital as predictors

## Results

The analysis shows that the relationship between initial income and subsequent economic growth varies across time periods. The regression results also examine the association between human capital and economic growth.

## Project Files

- `income_convergence.r` — R code for data processing, visualization, and regression analysis
- `income_convergence_plot.png` — Income convergence plots
- `regression_results.csv` — Regression results
